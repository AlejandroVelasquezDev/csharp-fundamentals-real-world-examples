# 📚 Simulador de Aprobación de Crédito Educativo

Este ejemplo muestra cómo usar **operadores relacionales en C#** para simular la evaluación de una solicitud de crédito educativo bancario. 

Está diseñado como parte del repositorio **Fundamentals of C#** y busca enseñar conceptos de forma aplicada, profesional y realista.

## 🚀 ¿Qué hace el programa?

Solicita información al usuario como:
- Edad
- Estado laboral
- Tiempo en el empleo actual
- Ingreso mensual
- Gastos mensuales
- Monto del préstamo a solicitar

Luego, valida si el usuario cumple las condiciones mínimas para que un banco apruebe el crédito, como:

- Ser mayor de edad
- Estar trabajando
- Tener más de 6 meses de antigüedad laboral
- Ingresos superiores al salario mínimo
- Nivel de endeudamiento aceptable

## 🧮 Conceptos cubiertos

- Uso de operadores relacionales (`>=`, `<=`, `==`, `>`, etc.)
- Declaración y uso de variables
- Conversión de tipos (`string` a `int`/`decimal`)
- Condicionales (`if`, `else`)
- Lectura de datos desde consola

## 🧠 ¿Por qué es útil?

Este ejemplo no solo muestra el uso de operadores, sino que representa un caso real que podría formar parte de una aplicación bancaria básica, útil en procesos de selección o entrevistas técnicas.

## 📦 Cómo ejecutarlo

1. Abre el proyecto en Visual Studio.
2. Ejecuta el método `ExampleEducationLoan.Run()` desde el `Main` (ajusta `Program.cs` si es necesario).
3. Ingresa los datos solicitados en consola.
4. Recibe el resultado con detalles.
